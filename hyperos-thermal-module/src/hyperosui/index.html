注意事项
使用前请仔细阅读
1. 零档可能导致设备过热请谨慎选择
2. 充电档位建议：亮屏充电不宜使用过高档位
3. 游戏包名：需准确填写可通过 MT 管理器查看当前应用包名
4. 刷新率锁定：仅支持设备支持的刷新率
5. 旁路供电：仅支持部分设备 需自行测试
6. 模块关闭：卸载或禁用后，自动恢复系统默认温控，无残留

场景功能说明
一. 普通场景
1. 触发条件：未进入充电或游戏状态时
2. 作为兜底策略，其他场景不生效时自动应用
3. 适用场景：日常刷微博、微信、浏览网页等轻度使用
4. 推荐系统默认
二. 充电场景
1. 触发条件：设备接入充电器
2. 亮屏充电：边充边玩时的温控策略
3. 息屏充电：屏幕关闭时使用的温控策略
4. 亮屏推荐零档 | 息屏推荐三档
三. 游戏场景
1. 触发条件：当前前台应用匹配到对应应用
2. 支持锁定刷新率
3. 支持添加 / 删除游戏包名
4. 推荐零档
场景判断优先级
模块总开关 → OFF → 恢复系统默认温控
游戏场景 → 匹配前台应用 → 应用游戏档位（含独立应用档位）
充电场景 → 检测充电状态 → 应用充电档位（亮屏 / 息屏分别判断）
普通场景 → 应用默认档位（兜底策略）
